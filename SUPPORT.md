# Support

- **Questions and usage help:** open a [GitHub discussion](https://github.com/CyprisTech/terraform-openstack-tenant/discussions) or an issue with the *question* label.
- **Bugs:** use the [bug report template](https://github.com/CyprisTech/terraform-openstack-tenant/issues/new?template=bug_report.yml).
- **Feature requests:** use the [feature request template](https://github.com/CyprisTech/terraform-openstack-tenant/issues/new?template=feature_request.yml).
- **Security issues:** follow [SECURITY.md](SECURITY.md), never a public issue.

This project is maintained on a best-effort basis; there is no guaranteed response time outside security reports.
